Third-party dependencies retain their own licenses. During desktop builds,
scripts/build-notices.ts inventories installed runtime and documentation
packages from the lockfiles, preserving their license/notice files (or their
README when a package omits separate license files). The generated inventory

license expressions and upstream source/package URLs. This inventory is not
an assertion that every upstream package ships complete license information.

See LICENSES/sharp-libvips-1.3.4-notices.txt for upstream's component inventory,

LGPL-3.0.txt and GPL-3.0.txt for full license texts. No OntoLab restriction
prohibits modifying/replacing these libraries or reverse engineering to debug
such modifications.
